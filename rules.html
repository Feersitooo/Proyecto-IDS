Cómo funciona aquí

  • Debes tener la cuenta activa, estar habilitado y no tener préstamos vencidos.
  • Cada colección tiene su propio cupo. Las asignaciones para retiro cuentan para evitar sobrepasarlo después.
  • Una solicitud pendiente no retiene ejemplares ni consume cupo.
  • La aprobación asigna una copia. Solo la entrega física inicia el préstamo.
  • El administrador confirma la fecha y hora exactas de devolución.
  • Los avisos de próximo vencimiento aparecen hasta {{ threshold }} horas antes. Este umbral es una decisión del prototipo.

Qué falta validar

  • Días hábiles, fines de semana, feriados y horarios efectivos de devolución. La sugerencia usa días calendario.
  • Automatización de multas y duración de sanciones: las fuentes contienen indicaciones diferentes.
  • Vigencia de asignaciones sin retiro, reglas de otros tipos de usuarios y colecciones.
  • Datos e identificación institucional. Este prototipo usa información ficticia.

No se calculan multas. Biblioteca administra la habilitación de las cuentas.
